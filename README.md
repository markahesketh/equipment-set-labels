# Equipment Set Labels

World of Warcraft addon that displays equipment set names as text labels on item icons in your bags, bank, and character panel.

![WoW Interface Version](https://img.shields.io/badge/WoW-12.0%20Midnight-blue)
![License](https://img.shields.io/badge/license-MIT-green)

## Features

- Yellow text overlays showing which equipment sets contain each item
- Displays up to 3 set names per item, with "+" indicator for additional sets
- Works in bags, bank, and character panel
- Toggle visibility per location via options panel
- Set names truncate at 5 characters for readability

## Installation

1. Download and extract to your WoW AddOns folder:
   ```
   World of Warcraft/_retail_/Interface/AddOns/EquipmentSetLabels
   ```
2. Restart WoW or type `/reload` in-game

## Usage

Labels appear automatically on items that belong to equipment sets.

Open the options panel to toggle label visibility:
```
/esl
```
or
```
/equipsetlabels
```

Options available:
- Show in bags
- Show in bank
- Show on equipped items
